Follow the installation steps at [IoT installation media](<>) _This test requires that you have a USB keyboard with a USB hub and a USB keyboard without a USB hub._

Once logged in, verify that: A connected USB keyboard with a USB hub works: 

  * when connected to a USB2 (black) port
  * when connected to a USB3 (blue) port


A connected USB keyboard without a USB hub works: 

  * when connected to a USB2 (black) port
  * when connected to a USB3 (blue) port
