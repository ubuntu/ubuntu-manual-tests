Select a language for the install and press Enter
Select a location for the install and press Enter
On Keyboard Layout select No and press Enter
Select the origin of the keyboard and press Enter /!\ The default for your location and language should already be selected.
Select the layout you wish to use on the keyboard and press Enter /!\ The default for your location and language should already be selected.
Add a hostname for the machine and press Enter
Select Manual and press Enter
Select Configure iSCSI volumes
Select Log into iSCSI targets /!\ If the machine is diskless, these steps will appear before selecting the partition scheme
Enter the IP address of the iSCSI target
Leave the indicator username blank
Select a target from the list
Select Finish
On the list of partitions, select the new one (VIRTUAL DISK)
Select pri/log ""drive size"" FREE SPACE and press Enter
Select Create a new partition and press Enter
Change the size to 20.0 GB and press Enter /!\ Alter for smaller drives
Select Primary and press Enter
Select Beginning and press Enter
Select Use as: line and press Enter
Select Ext4 journaling file system and press Enter
Select Done setting up the partition and press Enter
Select pri/log ""drive size"" FREE SPACE and press Enter
Select Create a new partition and press Enter
Change the size to 2.0 GB and press Enter /!\ Alter for smaller drives
Select Logical and press Enter
Select Beginning and press Enter
Select Use as: line and press Enter
Select swap area and press Enter
Select Done setting up the partition and press Enter
Select pri/log ""drive size"" FREE SPACE and press Enter
Select Create a new partition and press Enter
Press Enter to use the whole of the space remaining
Select Logical and press Enter
Select Beginning and press Enter
Select Use as: line and press Enter
Select Ext4 journaling file system and press Enter
Select Done setting up the partition and press Enter
Select Finish partitioning and write changes to disk and press Enter
Select Yes to accept the changes and press Enter
Type in your name and press Enter
Add a username and press Enter
Add a password and press Enter
Confirm your password and press Enter
Select No for encrypted home directory and press Enter
Input http proxy info or press Enter
Wait for a while /!\ The install may seem like it has locked at 6% but is actually working in the background.
Select Yes to setting your clock to utc and press Enter
Remove the cd and press Enter
This will then reboot the machine log in and check the desktop is installed
